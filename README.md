# 🌸 BloomJobs — Job Board App

A full-stack job board application built with **React** and **Supabase**.

## 🚀 Features

- 📋 View all job listings sorted by newest
- 🔍 Click any job to see full details
- ✍️ Post new job openings
- 📨 Submit applications with cover letters
- 📂 View all applications per job (expandable cover letters)

## 🛠️ Tech Stack

- **Frontend:** React, React Router DOM
- **Backend/Database:** Supabase (PostgreSQL)
- **Styling:** Custom CSS (pink theme 🌸)

## ⚙️ Setup

1. Clone the repo
2. Run `npm install`
3. Add your Supabase URL and Key to `supabaseClient.js`
4. Run `npm start`
